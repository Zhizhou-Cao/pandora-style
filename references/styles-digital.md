# Digital and Geometric Styles

Use computational structure locally and preserve the photograph elsewhere. Avoid generic effects unrelated to source geometry.

| Slug | Fit | Regional visual contract | Avoid |
|---|---|---|---|
| `pixel-art` | both | Deliberate low-resolution clusters, controlled palette and recognizable silhouette without anti-aliasing. | tiny noisy pixels, game UI, global downsampling |
| `ordered-dither` | both | Bayer-like ordered dot pattern converting local tones into a limited palette, with stable pattern scale. | random film grain, moire overload |
| `ascii-halftone` | geometry | Monospaced character density maps local luminance; characters stay small and subordinate. | readable paragraphs, fake code screen |
| `glitch-datamosh` | geometry | Directional block displacement, frame residue and compression trails following source motion or axes. | random rainbow noise, damaged whole image |
| `chromatic-channel-shift` | both | Restrained RGB separation along selected high-contrast contours and one directional offset. | global chromatic aberration, neon glow |
| `low-poly` | geometry | Unequal planar facets simplify local volume and value while preserving silhouette. | uniform triangulation, 3D render lighting |
| `vector-flat` | both | Clean source-derived silhouette planes, minimal gradients, limited palette and controlled negative shapes. | logo conversion, generic stock illustration |
| `isometric-fragment` | geometry | Selected architectural plane reinterpreted with consistent isometric axes and simplified blocks. | whole-scene perspective replacement |
| `topographic-contours` | both | Nested contour lines track source depth, value or silhouette and thin out into quiet areas. | arbitrary map lines, fake labels |
| `voronoi-shards` | geometry | Unequal cells aligned to local feature density, restrained glass/shard segmentation and source palette. | uniform cell size, explosion effect |
| `fish-scale-tessellation` | both | Overlapping scale-like arcs grow or shrink with local depth and follow the subject's directional flow. | global wallpaper, perfectly regular scales |
| `scanline-crt` | geometry | Horizontal scanlines, slight phosphor bloom and restrained channel bleed within source-aligned panels. | retro UI frame, heavy curvature |
| `thermal-map-digital` | semantic | False-color bands mapped consistently to local luminance or semantic mass, with one defined palette. | arbitrary rainbow gradient, legends by default |
| `generative-flow-field` | semantic | Sparse directional curves follow source gradients, motion, wind, hair, water or cloud flow. | unrelated spaghetti lines, full-field density |
| `generative-particles` | semantic | Particle density reconstructs selected forms and disperses along real movement or atmosphere. | generic sparkle, random star field |
| `wireframe` | geometry | Sparse mesh lines describe major planes and silhouette over a quiet ground, source perspective retained. | dense 3D model, glowing cyberpunk grid |
| `holographic-iridescence` | semantic | Thin angle-dependent color bands suggested through restrained spectral shifts on selected reflective forms. | full rainbow foil, glossy product mockup |
| `gradient-mesh` | semantic | Smooth limited-color field follows source volume and light with a few visible control transitions. | generic app gradient, global soft blur |
