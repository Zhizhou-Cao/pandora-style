# Print and Reproduction Styles

Use the row as a compact Regional Style Contract. Apply the global color policy unless the row declares a process-native palette.

| Slug | Fit | Regional visual contract | Avoid |
|---|---|---|---|
| `risograph` | both | Spot-color ink, porous grain, slight plate misregistration, broken coverage, one or two source-derived color separations. | glossy CMYK, perfect registration, neon glow |
| `xerox-punk` | both | Harsh toner black, crushed highlights, photocopy generations, scan streaks, ragged type fragments, abrasive contrast. | smooth gradients, clean vector polish |
| `newsprint-halftone` | both | Coarse AM dots, gray recycled paper, limited ink density, dot gain, clipped newspaper crop. | fine photographic smoothness, glossy stock |
| `screenprint` | both | Opaque flat ink layers, stencil-defined shapes, occasional mesh texture, bold source-aligned separations. | airbrushed shading, excessive colors |
| `letterpress` | geometry | Flat paper with shallow ink impression cues, uneven pressure, worn type or rules, restrained solid forms. | deep 3D embossing, drop shadows |
| `linocut` | semantic | Broad carved contours, white gouges, simplified silhouettes, assertive black/one-color relief ink. | tiny engraving detail, smooth vector lines |
| `woodcut` | both | Directional carved grain, compressed tonal masses, broken contour, visible relief-print character. | photorealistic shading, uniform grain |
| `wood-engraving` | semantic | Fine white-line engraving against dense black, cross-hatched tonal modeling, small controlled detail. | allover micro-detail, generic scratches |
| `etching` | semantic | Fine irregular intaglio lines, cross-hatching, plate-tone residue, delicate source contours. | clean technical vector, thick cartoon line |
| `aquatint` | both | Granular tonal fields, acid-bitten value steps, soft watercolor-like shadows, sparse etched contour. | dot-screen halftone, glossy color |
| `lithograph` | both | Greasy crayon texture, soft stone grain, broad tonal drawing, slightly uneven flat ink. | sharp digital edges, plastic surfaces |
| `photogravure` | semantic | Deep velvety blacks, continuous etched tonal range, soft copperplate grain, archival paper. | coarse comic dots, bright multi-color |
| `pochoir-stencil` | geometry | Crisp hand-cut stencil planes, brushed pigment variation, 2–4 flat source-resonant shapes. | sprayed graffiti overspray, gradients |
| `monotype` | semantic | One-off transferred ink, wiped passages, ghost impressions, soft pressure edges, painterly uncertainty. | repeated identical marks, crisp tiling |
| `collotype` | semantic | Fine reticulated gelatin grain, continuous muted tone, delicate archival reproduction softness. | coarse dots, hard posterization |
| `rubber-stamp` | both | Repeated source-shape stamps, uneven pressure, missing corners, compact ink rhythm. | decorative icons unrelated to source |
| `cyanotype-blueprint` | both | Process-native Prussian blue field with white or pale source silhouette and blueprint linework. | extra accent hues, purple neon |
| `duotone-offset` | both | Two offset ink plates, visible dot gain and slight registration slip; neutral plus one source-derived hue. | full-spectrum color, perfect digital blend |
